# Personas

### Persona primária: Júlia Sousa

![foto de rosto ilustrativa](imagens/persona_julia.jpeg)

| Campo | Descrição |
| :---- | :---- |
| **Idade** | 21 anos |
| **Ocupação** | Estudante que trabalha em tempo integral. |
| **Citação** | "Só faço alguma coisa quando é necessário mesmo, me baseio na memória e no visual." |
| **Objetivos** | Lembrar de coisas básicas do dia a dia; encontrar veterinários bons e acessíveis;   |
| **Nível de tecnologia** | Alto — sempre em algum dispositivo. |
| **Frustração principal** | Não tem muito tempo e às vezes se esquece de coisas simples. |

### Mapa de Empatia — Júlia Sousa

| Quadrante | Descrição |
| :---- | :---- |
| **Vê** | Muita correria no dia a dia; preços caros em veterinários; observa se o pet parece bem |
| **Ouve** | Recomendações informais de clínicas por amigos e familiares; resmungos do pet porque acabou a água da vasilha. |
| **Diz e faz** | Percebe visualmente se o pet está precisando de algum cuidado como banho e tosa, quando precisa ela faz.  |
| **Pensa e sente** | Não se preocupa muito com cuidados adicionais, pensa que consegue lidar com tudo mesmo se esquecendo às vezes.  |
| **Dores** | Falta de tempo pra tentar ser mais organizada cuidando do pet, além de não ter procurado/encontrado uma ferramenta boa o suficiente para ajudar. |
| **Ganhos** | Saberia qual a próxima tarefa pendente, não precisaria se preocupar em esquecer uma consulta. |

### Persona primária: Ana Clara

![foto de rosto ilustrativa](imagens/persona_anaclara.jpeg)

| Campo | Descrição |
| :---- | :---- |
| **Idade** | 27 anos |
| **Ocupação** | Trabalha em tempo integral e faz cursos esporádicos. |
| **Citação** | "Divido as tarefas com a minha família, mas a gente se perde e as coisas atrasam!" |
| **Objetivos** | Ter uma visão geral do que precisa ser feito; não deixar uma consulta ou tarefa atrasar porque a comunicação falhou. |
| **Nível de tecnologia** | Alto — frequentemente usa celular ou computador. |
| **Frustração principal** | Dificuldade de se lembrar, organizar e manter rotinas para todos os seus pets de forma personalizada. |

### Mapa de Empatia — Ana Clara

| Quadrante | Descrição |
| :---- | :---- |
| **Vê** | Desorganização na casa e caderno de anotações cheio de datas. |
| **Ouve** | Frases como "achei que você já tinha feito isso" |
| **Diz e faz** | Tenta se lembrar de necessidades diárias dos pets de forma visual e de vez em quando anota algumas datas no papel. |
| **Pensa e sente** | Se sente sobrecarregada por não saber exatamente o que está sendo feito, tudo é muito informal. |
| **Dores** | Tem dificuldade em compartilhar cuidados com a família e saber se alguma tarefa já foi feita, acaba se perdendo; muitas vezes posterga alguma tarefa porque se esqueceu. |
| **Ganhos** | Não se esqueceria das vacinas e dos medicamentos, teria lembretes de quando realizar determinada tarefa e conseguiria separar cuidados para pets diferentes e para membros diferentes da família. |
